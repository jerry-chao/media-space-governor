# 02 — Classify authorized media with Library Access Coverage

**What to build:** After a user grants Photos access, the app inventories their authorized visible photos and videos and presents real shallow Governance Classification with clear Library Access Coverage. The user can tell whether the result covers the full library or only a limited selection, see the scanned count, and review safe archive recommendations without any media upload or cleanup.

**Blocked by:** 01 — Truthfully represent unmeasured Space Saving Opportunity.

**Status:** ready-for-agent

- [ ] The app requests Photos access with an accurate Media Space Governance purpose and handles authorized, limited, denied, restricted, and unavailable outcomes.
- [ ] Authorized visible screenshots, camera photos, and ordinary videos receive the corresponding shallow Content Hint and Governance Classification.
- [ ] A limited Photos selection is visibly identified as partial Library Access Coverage together with its scanned resource count.
- [ ] Hidden and unsupported assets are excluded; unavailable required metadata is not fabricated.
- [ ] A favorite asset is represented as a Protected Resource and excluded from default Governance Recommendations.
- [ ] The feature remains On-Device Analysis only: it reads no media content, performs no Remote Archive upload, and never removes a Local Primary.
- [ ] Automated adapter-contract tests and a real-device smoke check cover permission recovery, full and limited coverage, and observable classification results.
