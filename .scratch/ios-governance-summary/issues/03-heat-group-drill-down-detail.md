# 03 — Heat group drill-down detail page

**What to build:** Tapping a Usage Heat group opens a detail page listing that group's member media in Content Class sections, showing content class, heat, Protected mark, and local-size state. The detail page shares the same live measurement source as the summary, so both stay consistent.

**Blocked by:** 02 — Governance summary main screen.

**Status:** ready-for-agent

- [ ] Tapping a heat group card navigates to that group's detail page.
- [ ] The detail page lists member media grouped by Content Class sections (screenshots / camera photos / ordinary videos).
- [ ] Rows show Content Class, Usage Heat, Protected mark, and local-size state (measured / unmeasured / unavailable-on-device).
- [ ] The detail page reflects live measurement results consistently with the summary it came from.
- [ ] Returning to the summary shows updated numbers without re-scanning.
- [ ] Real-device smoke check: tap-through for cold, lukewarm, and active groups with real media.
